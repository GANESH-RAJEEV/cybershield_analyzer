Generate the six-row standard-scenario evidence table: Normal, alternate link disabled, link saturated, device failed, critical device failed, and segment isolated.

Targets are computed from the current graph and can be edited before the table is copied or exported.

Scenario Reference

  • Hardware failure - device becomes Failed.
  • Link failure - directed link becomes Disabled.
  • Bandwidth reduction - cuts link capacity by a percentage.
  • Link saturation - adds background traffic percentage.
  • Communication blocking - link becomes Blocked.
  • Router compromise - router becomes Compromised and degrades outgoing capacity.
  • VPN disruption - VPN link becomes Disabled.
  • AP failure / jamming - access point and its Wi-Fi links fail.
  • Segment isolation - every crossing link of a segment is disabled.

Report §8.3 — Standard Scenarios

Each row is recomputed from the current topology, endpoints and utilization threshold. The first row is the unchanged baseline; the remaining five rows apply one incident to a clone and compare the resulting max flow and shortest latency.

CSV cells that begin with =, +, - or @ are prefixed with an apostrophe to prevent spreadsheet formula injection. Values are generated live; no scenario numbers are hard-coded in the UI.
